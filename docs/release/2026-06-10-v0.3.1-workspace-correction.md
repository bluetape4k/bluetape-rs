# v0.3.1 워크스페이스 릴리스 정정

날짜: 2026-06-10
마일스톤: `0.3.0`
이슈: #70

## 요약

`v0.3.1`은 `0.3.0` 마일스톤을 정정하는 릴리스다. 이전 `v0.3.0` 태그와
GitHub Release는 생성되었지만 `bluetape-rs-codec@0.3.0`만 crates.io에
게시되었다. 나머지 워크스페이스는 여전히 `0.1.1` 또는 `0.2.0` 버전이어서
릴리스가 마일스톤 수준의 패키지 의도와 일치하지 않았다.

이 릴리스는 현재 워크스페이스의 모든 패키지를 `0.3.1`로 정렬하고 전체
워크스페이스를 `0.3.x` 안정 라인으로 게시한다.

## 패키지 범위

| 패키지 | 버전 |
|---|---:|
| `bluetape-rs` | `0.3.1` |
| `bluetape-rs-core` | `0.3.1` |
| `bluetape-rs-logging` | `0.3.1` |
| `bluetape-rs-test` | `0.3.1` |
| `bluetape-rs-collections` | `0.3.1` |
| `bluetape-rs-async` | `0.3.1` |
| `bluetape-rs-codec` | `0.3.1` |

## 릴리스 메모

- `bluetape-rs-codec@0.3.0`이 이미 crates.io에 게시되었으므로 `v0.3.0`은
  변경할 수 없다.
- `v0.3.1`은 `0.3.0` 마일스톤의 완전한 워크스페이스 릴리스로서 `v0.3.0`을
  대체한다.
- 루트 파사드와 모든 집중 크레이트는 같은 패키지 버전을 사용한다.

## 검증 계획

| 게이트 | 명령 |
|---|---|
| 포맷 | `cargo fmt --all --check` |
| 공백 | `git diff --check` |
| 테스트 | `cargo test --workspace --all-features --locked` |
| 린트 | `cargo clippy --workspace --all-targets --all-features --locked -- -D warnings` |
| 문서 | `RUSTDOCFLAGS="-D warnings" cargo doc --workspace --all-features --no-deps --locked` |
| 게시 dry-run | `cargo publish --workspace --dry-run --locked` |
