# v0.3.1 Workspace 릴리스 정정

날짜: 2026-06-10
Milestone: `0.3.0`
이슈: #70

## 요약

`v0.3.1`은 `0.3.0` milestone을 정정하는 릴리스입니다. 이전
`v0.3.0` tag와 GitHub Release는 생성되었지만
`bluetape-rs-codec@0.3.0`만 crates.io에 publish되었습니다. 나머지
workspace는 여전히 `0.1.1` 또는 `0.2.0` version이었으므로 릴리스가
milestone-level package intent와 일치하지 않았습니다.

이 릴리스는 현재 workspace package를 모두 `0.3.1`로 맞추고 전체
workspace를 `0.3.x` 안정 릴리스 train으로 publish합니다.

## 릴리스 노트

- `bluetape-rs-codec@0.3.0`이 이미 crates.io에 publish되었으므로
  `v0.3.0`은 immutable입니다.
- `0.3.0` milestone의 complete workspace release로 `v0.3.1`이
  `v0.3.0`을 대체합니다.
- root facade와 모든 focused crate가 동일한 package version을 사용합니다.

## 검증 계획

| Gate | Command |
|---|---|
| Formatting | `cargo fmt --all --check` |
| Whitespace | `git diff --check` |
| Tests | `cargo test --workspace --all-features --locked` |
| Lints | `cargo clippy --workspace --all-targets --all-features --locked -- -D warnings` |
| Docs | `RUSTDOCFLAGS="-D warnings" cargo doc --workspace --all-features --no-deps --locked` |
| Publish dry-run | `cargo publish --workspace --dry-run --locked` |
