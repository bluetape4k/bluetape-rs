# v0.4.0 압축 릴리스 준비 상태

## 범위

`v0.4.0`은 `bluetape-rs`의 첫 Rust 네이티브 압축 라인을 게시한다.
릴리스는 알고리즘 의존성을 옵트인으로 유지하고 기존 워크스페이스 전체 버전
정책을 보존한다. 게시 가능한 모든 워크스페이스 크레이트를 같은 버전으로
릴리스한다.

## 보류 범위

- Archive/zip 헬퍼.
- Serde 중심 직렬화 래퍼와 serializer-compressor 조합.
- Testcontainers, SQL, resilience, leader election, cache coordination, AWS,
  graph, text, audit 및 rule-engine 범위.
- 기본값 중심의 전역 압축 정책.
- `bluetape-rs-workshop` 예제. 워크숍 작업은 이 저장소 외부에서 추적한다.

## 릴리스 실행 계획

1. 이 릴리스 준비 상태 PR을 `develop`에 병합한다.
2. PR 병합 후 #80 및 #73을 닫는다.
3. 모든 마일스톤 이슈를 닫은 뒤 `0.4.0` 마일스톤을 닫는다.
4. 릴리스 PR을 통해 검증된 `develop` 트리를 `main`으로 승격한다.
5. `main`에 `v0.4.0` 태그를 만든다.
6. crates.io에 워크스페이스 패키지를 `0.4.0`으로 게시한다.
7. `v0.4.0`에서 GitHub Release를 생성한다.
8. 게시 가능한 모든 워크스페이스 크레이트가 crates.io에 표시되는지 확인한다.

## 릴리스 전 근거

| 확인 항목 | 상태 | 근거 |
|---|---|---|
| crates.io 최신 라인 확인 | 통과 | `bluetape-rs`와 `bluetape-rs-core`의 최신 버전은 `0.3.1`이고, `bluetape-rs-compression`은 아직 등록되지 않았다. |
| 기존 `v0.4.0` 태그/릴리스 확인 | 통과 | 이 PR 이전에는 로컬/원격에 `v0.4.0` 태그나 GitHub Release가 없다. |
| 안정 기준선 | 통과 | `origin/main`과 `v0.3.1^{}`가 모두 `6cef44048b97d2d933fcf42e34fd6f3267b4ff30`을 가리킨다. |
| 개발 기준선 | 통과 | 이 PR 이전의 `origin/develop`은 `71b3a564025b66d3228df5950e23c08019a6f543`을 가리킨다. |
| 워크스페이스 메타데이터 | 통과 | `cargo metadata --no-deps --format-version 1` 실행 결과, 게시 가능한 모든 패키지는 `0.4.0`을 보고하고 `compression-benchmark`는 `publish=[]`를 보고한다. |
| 포맷팅 | 통과 | `cargo fmt --all --check`. |
| 테스트 | 통과 | `cargo test --workspace --all-features --locked`. |
| Clippy | 통과 | `cargo clippy --workspace --all-targets --all-features --locked -- -D warnings`. |
| Rustdoc | 통과 | `RUSTDOCFLAGS="-D warnings" cargo doc --workspace --all-features --no-deps --locked`. |
| 게시 드라이런 | 통과 | `cargo publish --workspace --dry-run --locked`; 커밋 전 `--allow-dirty`를 사용한 dirty 사전 점검도 통과했다. |
| 공백 | 통과 | `git diff --check`. |
