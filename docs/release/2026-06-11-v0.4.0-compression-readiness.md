# v0.4.0 Compression 릴리스 준비 상태

## 범위

`v0.4.0`은 `bluetape-rs`의 첫 Rust 네이티브 compression train을
publish합니다. 이 릴리스는 algorithm dependency를 opt-in으로 유지하고
기존 workspace-wide version policy를 보존합니다. publish 가능한 모든
workspace crate는 동일한 version으로 릴리스합니다.

## 릴리스 실행 계획

1. 이 release-readiness PR을 `develop`에 merge합니다.
2. PR을 merge한 뒤 #80과 #73을 닫습니다.
3. 모든 milestone issue를 닫은 뒤 milestone `0.4.0`을 닫습니다.
4. release PR을 통해 검증한 `develop` tree를 `main`으로 promote합니다.
5. `main`에서 `v0.4.0`을 tag합니다.
6. crates.io에 workspace package `0.4.0`을 publish합니다.
7. `v0.4.0`에서 GitHub Release를 생성합니다.
8. publish 가능한 모든 workspace crate가 crates.io에 표시되는지 검증합니다.
