# v0.3.0 코덱 릴리스 준비 상태

날짜: 2026-06-10

이슈: #58
마일스톤: `0.3.0`

## 범위

이 문서는 `0.3.0` 코덱 마일스톤의 준비 상태 근거를 기록한다. 태그 생성,
크레이트를 배포하거나 `develop`에서 `main`으로 승격하거나 GitHub Release를
생성하지 않는다.

## 릴리스 구성

- `bluetape-rs-codec` `0.3.0`
- 선택적인 루트 크레이트 파사드 피처: `codec`
- 엄격한 hex 인코딩 및 디코딩
- 패딩 및 비패딩 변형을 지원하는 표준 및 URL-safe Base64 헬퍼
- Bitcoin Base58 헬퍼
- 바이트 지향 Base62 헬퍼
- UTF-8 텍스트/바이트 경계 헬퍼
- 타입이 지정된 디코드 오류와 공개 크레이트 경계 테스트

## 릴리스 주의 사항

이 문서는 릴리스 준비 상태 근거만 제공한다. 안정 릴리스에는 명시적인
릴리스 승격 워크플로가 여전히 필요하다. 준비 PR을 `develop`에 병합하고,
검증한 트리를 `main`으로 승격한 뒤 `main`에서 태그를 생성하고 GitHub
Release를 만든 다음 로컬 브랜치를 동기화해야 한다.
