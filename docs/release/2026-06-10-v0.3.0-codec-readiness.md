## 릴리스 구성

- `bluetape-rs-codec` `0.3.0`
- 선택형 root crate facade feature: `codec`
- strict hex encoding 및 decoding
- padded 및 unpadded variant를 포함한 Base64 standard 및 URL-safe helper
- Bitcoin Base58 helper
- byte-oriented Base62 helper
- UTF-8 text/byte boundary helper
- typed decode error 및 public crate-boundary test

## 릴리스 주의 사항

이 문서는 release-readiness evidence만 제공합니다. stable release에는
명시적 release-promotion workflow가 여전히 필요합니다. readiness PR을
`develop`에 merge하고, 검증한 tree를 `main`으로 promote한 뒤 `main`에서
tag를 생성하고 GitHub Release를 만든 다음 local branch를 동기화해야 합니다.
